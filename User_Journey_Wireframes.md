# User Journey Wireframes (Textual, Screens 1–12) — Flawless AceTouch v1.0

First consultation → check-in. Tone: supportive/expert/reassuring. Each screen: Purpose / Key UI / CTA / Exit criteria.

**1. Landing / Value intro.** Purpose: convert to start. UI: hero "Understand your skin in <5 min", 3 outcome bullets, social-proof line, Start CTA. CTA: Start free consultation. Exit: tap Start.
**2. Welcome & Goal (Q1–Q3).** Purpose: set direction. UI: goal chips (max 3), frustration textbox, effort tier radio, progress 1/6. CTA: Continue. Exit: Q1+Q3 valid.
**3. Skin Profile (Q4–Q6).** Purpose: type + concerns. UI: skin-type cards, concern chips (max 3), conditional breakout pattern. CTA: Continue. Exit: Q4+Q5 valid.
**4. Lifestyle + Current routine (Q7–Q8).** Purpose: context. UI: lifestyle chips, AM/PM mini-form, love/hate fields, Skip link. CTA: Continue / Skip. Exit: always (optional).
**5. Sensitivities + Preferences (Q9–Q11).** Purpose: safety + fit. UI: allergen chips + reaction severity (conditional), preference chips, avoid-textbox. CTA: Continue. Exit: Q9+Q10 valid.
**6. Context + Photo (Q12–Q14).** Purpose: climate/age/photo. UI: climate select, age band, upload tiles (1–3, consent checkbox, guidelines). CTA: See my analysis. Exit: Q13 + consent-if-photo.
**7. Analysis & Insights.** Purpose: build trust. UI: top 2–3 priority cards (score-derived why-line), "What this means" plain language, Adjust answers link. CTA: Get my routine. Exit: tap CTA.
**8. Personalized Routine.** Purpose: actionable plan. UI: AM/PM timeline (order, amount, frequency), conflict-safe badges (e.g. "alternate nights"), Save routine. CTA: See product picks. Exit: view or save.
**9. Product Suggestions.** Purpose: confident choice. UI: 3–6 cards (concern tag, why-fits, badges: fragrance-free etc., budget/premium label). CTA: Explore custom option / Done. Exit: tap either.
**10. Custom Formulation (conditional).** Purpose: deeper personalization only when valuable. UI: value line ("covers 2 of your 3 priorities"), concept card (purpose, keys+%, slot), adjusters (texture/scent/intensity), else "routine covers it" state. CTA: Order / Save for later / Skip. Exit: any choice.
**11. Next Steps + Home (Saved).** Purpose: no "now what?". UI: 3-step checklist (tonight, this week, check-in date auto-set 14–28d), routine saved to library, journal nudge. CTA: Go to my routine. Exit: checklist shown + saved.
**12. Check-in (Day 14–28).** Purpose: refine + retain. UI: per-priority improved/same/worse, irritation? adherence?, journal recap, result delta (Keep/Adjust/Swap) + celebration copy, next check-in set. CTA: Update my routine. Exit: delta delivered.

Global: progress bar (1–6), Back always, Skip on optional, autosave + resume, derm-disclaimer path, empty states for library/journal.
