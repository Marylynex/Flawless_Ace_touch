# User Journey Wireframes (Textual, Screens 1-14) - Flawless AceTouch v1.1

First consultation -> expert request -> check-in. Tone: supportive/expert/reassuring. Each screen: Purpose / Key UI / CTA / Exit criteria. All experts/replies mock in V1. No diagnosis or live video.

**1. Landing / Value intro.** Purpose: convert to start. UI: hero "Get expert-reviewed skincare in <5 min", 3 outcome bullets, "a vetted expert reviews every case" line, Start CTA. CTA: Start free consultation. Exit: tap Start.
**2. Welcome & Goal (Q1-Q3).** Purpose: set direction. UI: goal chips (max 3), frustration textbox, effort tier radio, progress 1/6. CTA: Continue. Exit: Q1+Q3 valid.
**3. Skin Profile (Q4-Q6).** Purpose: type + concerns. UI: skin-type cards, concern chips (max 3), conditional breakout pattern. CTA: Continue. Exit: Q4+Q5 valid.
**4. Lifestyle + Current routine (Q7-Q8).** Purpose: context. UI: lifestyle chips, AM/PM mini-form, love/hate fields, Skip link. CTA: Continue / Skip. Exit: always (optional).
**5. Sensitivities + Preferences (Q9-Q11).** Purpose: safety + fit. UI: allergen chips + reaction severity (conditional), preference chips, avoid-textbox. CTA: Continue. Exit: Q9+Q10 valid.
**6. Context + Photo (Q12-Q14, mock-only).** Purpose: climate/age/photo. UI: climate select, age band, upload tiles (1-3 mock/test images, consent checkbox, guidelines). CTA: Meet my expert match. Exit: Q13 + consent-if-photo.
**7. Expert Match.** Purpose: confidence a qualified human reviews the case. UI: 1-3 matched expert cards (photo, name, credentials, specialty match reason, languages, rating, response window), "mock profiles" label, confirm-one selector. CTA: Send request to [Expert]. Exit: expert confirmed.
**8. Request Submitted + Status Tracking.** Purpose: transparency while waiting. UI: request summary (goals, concerns, photo count), status timeline submitted -> under review -> answered, expected window, "mock review" note, tips-while-waiting link. CTA: Got it / Track in My requests. Exit: request stored; status visible in library.
**9. Expert Reply - Analysis & Insights.** Purpose: build trust. UI: expert header (name, credentials, "mock reply" badge), top 2-3 priority cards (why-line), "What this means" plain language, Adjust answers link. CTA: Get my routine. Exit: tap CTA.
**10. Personalized Routine (expert-approved).** Purpose: actionable plan. UI: expert endorsement strip, AM/PM timeline (order, amount, frequency), conflict-safe badges (e.g. "alternate nights"), Save routine. CTA: See product picks. Exit: view or save.
**11. Product Suggestions.** Purpose: confident choice. UI: 3-6 cards (concern tag, why-fits, badges: fragrance-free etc., budget/premium label, expert-pick mark). CTA: Explore custom option / Done. Exit: tap either.
**12. Custom Formulation (conditional).** Purpose: deeper personalization only when valuable. UI: value line ("covers 2 of your 3 priorities"), concept card (purpose, keys+%, slot), adjusters (texture/scent/intensity), else "routine covers it" state. CTA: Order / Save for later / Skip. Exit: any choice.
**13. Next Steps + Home (Saved).** Purpose: no "now what?". UI: 3-step checklist (tonight, this week, check-in date auto-set 14-28d), request thread + routine saved to library, journal nudge. CTA: Go to my routine. Exit: checklist shown + saved.
**14. Check-in + Expert Follow-up (Day 14-28).** Purpose: refine + retain. UI: per-priority improved/same/worse, irritation? adherence?, journal recap, follow-up request status (submitted -> answered), expert follow-up reply (Keep/Adjust/Swap) + celebration copy, next check-in set. CTA: Update my routine. Exit: follow-up delta delivered.

Global: progress bar (1-6) through intake; Back always, Skip on optional, autosave + resume, derm-disclaimer path (no diagnosis), status timeline pattern reused for initial + follow-up requests, empty states for library/journal, "My requests" list shows all threads.
